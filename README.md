# Custom-Foliage
## Custom Foliage Creation Workflow

This project presents a procedural foliage creation workflow using SpeedTree and Adobe Substance 3D Designer for generating optimized vegetation assets suitable for real-time applications. The workflow combines procedural texture generation, vegetation modeling, mesh-based growth control, and automated optimization techniques to create scalable foliage for large environments.

Custom leaf textures are created in Adobe Substance 3D Designer using a node-based workflow, where multiple leaf references are combined into a single texture atlas. The resulting Base Color, Opacity, and Normal maps are imported into SpeedTree and assigned to procedural leaf generators. Vegetation structures, including trunks, branches, twigs, and leaves, are generated procedurally and refined through parameters such as density, scaling variation, orientation, and randomization to achieve natural-looking results.

The workflow also utilizes Mesh Forces to control vegetation growth around imported geometry. Custom meshes can influence the direction and behavior of branches, vines, and roots, allowing vegetation to naturally conform to architectural structures and environmental assets. Automatic LOD generation and wind simulation further optimize the assets for real-time rendering while preserving visual quality.

### Key Features

• Procedural foliage generation using SpeedTree
• Custom leaf texture creation in Adobe Substance 3D Designer
• Texture atlas workflow for optimized rendering performance
• Mesh Force-based vegetation growth control
• Automatic Level of Detail (LOD) generation
• Realistic wind simulation and environmental interaction
• Scalable foliage creation for large environments
• Real-time rendering optimized vegetation assets
• Non-destructive procedural texture workflow
• Hybrid procedural modeling and texturing pipeline
